What this QR code generator does

This free QR code generator converts text into a scannable square pattern that any phone camera can read. Use it for a website link, a Wi-Fi login, an email draft or a tap-to-call phone number.

The pattern is calculated by code on this page, so the result appears instantly and your content isn’t sent anywhere. You choose the colors, the error correction level and the download size, then save a PNG or a scalable SVG.

Why use this free QR code generator

  • No signup, no watermark. The file you download has only your code on it.
  • Static codes that don’t expire. The content is stored in the pattern itself, so there’s no redirect and no subscription to lapse.
  • Private by design. Your link or Wi-Fi password is processed in your browser.
  • Print-ready SVG. Vector output stays sharp on a poster as well as a business card.
  • Built-in contrast check. The tool warns you when your colors are likely to scan badly.

Step-by-step guide

1. Choose the content type

“Link or text” works for web addresses and any plain message. Wi-Fi builds the standard network format that phones use to join a network. Email opens a draft with the address, and optionally a subject. Phone starts a call when scanned.

2. Enter your details

Include the full address, starting with https://, so every scanner treats it as a link. For phone numbers, add the country code, like +1 or +44.

3. Pick options

Medium error correction suits most uses. Choose High if the code will be printed on packaging that can get scuffed. Keep dark modules on a light background for the most reliable scans.

4. Test, then download

Point your phone camera at the preview before you save anything. Use PNG for web pages, slides and chat apps. Use SVG for print and for designers. You can also compress the PNG with Compress Image File if you need a lighter file.

QR code scanner vs QR code generator

A QR code generator creates the code. A QR code scanner reads it. This page is a generator: you enter your link, text, Wi-Fi details, email or phone number, and it draws the QR code for you to download.

You don’t need a separate QR code scanner to check your work. Most modern phones scan a QR code with the built-in camera app. Point the camera at the preview on your screen, tap the banner that appears, and confirm it opens the right page or action. If your camera doesn’t react, install a free scanner app and try again.

  • Generator (this tool): turns your content into a QR code image.
  • Scanner (your phone camera or app): reads a QR code and opens what is inside it.

Expert tips and common mistakes

Tips

  • Shorter content gives a larger, simpler pattern that scans from farther away. Shorten long links before you encode them.
  • As a rule of thumb, a code should be about one tenth as wide as the distance it’s scanned from.
  • Print a test copy at the final size and scan it on at least two phones.
  • Label the code with a few words, like “Scan for menu,” so people know what they’ll get.

Common mistakes

  • Inverting the colors with a light code on a dark background. Some scanners can’t read it.
  • Cropping the white margin to save space.
  • Using pale colors like yellow on white.
  • Stretching the image so modules aren’t square.
  • Skipping https:// so a link reads as plain text.

Troubleshooting

The code won’t scan

Check contrast first. Use a dark code on a light background, keep the white margin, and try a larger size.

“Too long for this error correction level”

Shorten the text, or switch to a lower error correction level such as Low.

My link opens as text

Start the address with https:// so scanners recognize it as a web link.

The Wi-Fi code doesn’t connect

Check the network name and password for typos, including capital letters, and choose the right security type.

Copy image doesn’t work

Some browsers don’t allow image copying. Use Download PNG instead.

The printed code looks blurry

Download the SVG, or the 2048 px PNG, and print at a fixed size without scaling it up in a document.

Glossary

Module
One of the small black or white squares that make up a QR code.
Quiet zone
The blank margin around the code that helps scanners find its edges.
Error correction
Extra data that lets a scanner rebuild the content when part of the code is damaged or covered.
Static QR code
A code that stores the content itself. It never expires and can’t be edited.
Finder pattern
The three large squares in the corners that tell a scanner where the code is and how it’s rotated. More at Wikipedia’s QR code article.

Will my QR code expire?

No. These are static QR codes, which means the content is encoded directly in the pattern. There’s no redirect, no tracking and no subscription behind them, so they keep working as long as the destination itself does.

How much text can a QR code hold?

The largest QR code can hold 2,953 bytes of text at the lowest error correction level, and less at higher levels. Shorter content makes a simpler pattern that scans faster and more reliably, so keep links and messages as short as you can.

Does it work on my phone?

Yes. The page is built for small screens, and you can download or copy the code straight from your phone. To test it, open your camera app and point it at the code on another screen or a printout.

Does it work offline?

Once the page has loaded, yes. Generating and downloading codes needs no internet connection because everything runs locally. You do need to be online the first time you open the page.

Which error correction level should I pick?

Medium is a good default. Levels L, M, Q and H can recover roughly 7%, 15%, 25% and 30% of damaged data. Choose Quartile or High for codes that will be printed on rough surfaces, but note that higher levels make the pattern denser.

What size and colors are best for printing?

Download the SVG for print, since it stays sharp at any size. Use dark modules on a light background, keep the white margin, and aim for at least 2 cm (about 0.8 in) across. Always scan a test print before you produce a large run.
